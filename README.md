# NativePerformanceKit

Monorepo for `react-native-performance-kit`, a React Native library (Turbo Native Module +
Codegen) that exposes process memory and FPS snapshots on Android and iOS.

- Library, API and metric semantics: [packages/react-native-performance-kit/README.md](./packages/react-native-performance-kit/README.md)
- Example app (Expo development build): [example/](./example)
- Architecture: [ARCHITECTURE.md](./ARCHITECTURE.md)
- Requirements and plan: [specs/spec.md](./specs/spec.md), [specs/plan.md](./specs/plan.md)
- Development, tests and CI: [CONTRIBUTING.md](./CONTRIBUTING.md)

Quick start: `corepack enable && yarn && yarn test`, then `yarn example ios` or `yarn example android`.
