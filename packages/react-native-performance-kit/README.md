# react-native-performance-kit

Native process memory and FPS snapshots for React Native

## Installation


```sh
npm install react-native-performance-kit
```


## Usage


```js
import { isMonitoring } from 'react-native-performance-kit';

// The public API is under construction (see specs/plan.md).
const monitoring = isMonitoring(); // false
```
